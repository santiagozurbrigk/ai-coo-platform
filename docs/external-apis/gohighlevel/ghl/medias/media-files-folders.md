# Media Files/Folders

Documentation for Files API

- [Get List of Files/Folders](https://marketplace.gohighlevel.com/docs/ghl/medias/fetch-media-content) — Fetches list of files and folders from the media storage
- [Upload File into Media Storage](https://marketplace.gohighlevel.com/docs/ghl/medias/upload-media-content) — If hosted is set to true then fileUrl is required. Else file is required. If adding a file, maximum allowed is 25 MB. For video files, the maximum allowed size is 500 MB.
- [Delete File or Folder](https://marketplace.gohighlevel.com/docs/ghl/medias/delete-media-content) — Deletes specific file or folder from the media storage
- [Update File/Folder](https://marketplace.gohighlevel.com/docs/ghl/medias/update-media-object) — Updates a single file or folder by ID
- [Create Folder](https://marketplace.gohighlevel.com/docs/ghl/medias/create-media-folder) — Creates a new folder in the media storage
- [Bulk Update Files/Folders](https://marketplace.gohighlevel.com/docs/ghl/medias/bulk-update-media-objects) — Updates metadata or status of multiple files and folders
- [Bulk Delete / Trash Files/Folders](https://marketplace.gohighlevel.com/docs/ghl/medias/bulk-delete-media-objects) — Soft-deletes or trashes multiple files and folders in a single request
