# Blogs

Documentation for Blogs

- [Check url slug](https://marketplace.gohighlevel.com/docs/ghl/blogs/check-url-slug-exists) — The 'Check url slug' API allows check the blog slug validation which is needed before publishing any blog post. Please use blogs/check-slug.readonly. you can find the POST ID from the post edit url.
- [Update Blog Post](https://marketplace.gohighlevel.com/docs/ghl/blogs/update-blog-post) — The 'Update Blog Post' API allows you update blog post for any given blog site. Please use blogs/post-update.write
- [Create Blog Post](https://marketplace.gohighlevel.com/docs/ghl/blogs/create-blog-post) — The 'Create Blog Post' API allows you create blog post for any given blog site. Please use blogs/post.write
- [Get all authors](https://marketplace.gohighlevel.com/docs/ghl/blogs/get-all-blog-authors-by-location) — The 'Get all authors' Api return the blog authors for a given location ID. Please use 'blogs/author.readonly'
- [Get all categories](https://marketplace.gohighlevel.com/docs/ghl/blogs/get-all-categories-by-location) — The 'Get all categories' Api return the blog categoies for a given location ID. Please use 'blogs/category.readonly'
- [Get Blog posts by Blog ID](https://marketplace.gohighlevel.com/docs/ghl/blogs/get-blog-post) — The 'Get Blog posts by Blog ID' API allows you get blog posts for any given blog site using blog ID.Please use blogs/posts.readonly
- [Get Blogs by Location ID](https://marketplace.gohighlevel.com/docs/ghl/blogs/get-blogs) — The 'Get Blogs by Location ID' API allows you get blogs using Location ID.Please use blogs/list.readonly
