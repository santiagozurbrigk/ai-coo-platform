# Brand Voices

Documentation for Brand Boards API

- [List Brand Voices](https://marketplace.gohighlevel.com/docs/ghl/brand-boards/list-brand-voices) — Get list of brand voices for a location
- [Create Brand Voice](https://marketplace.gohighlevel.com/docs/ghl/brand-boards/create-brand-voice) — Create a brand voice for a location
- [Get Brand Voice](https://marketplace.gohighlevel.com/docs/ghl/brand-boards/get-brand-voice) — Get a brand voice by ID
- [Update Brand Voice](https://marketplace.gohighlevel.com/docs/ghl/brand-boards/update-brand-voice) — Update a brand voice by ID
- [Delete Brand Voice](https://marketplace.gohighlevel.com/docs/ghl/brand-boards/delete-brand-voice) — Delete a brand voice by ID
- [Set Default Brand Voice](https://marketplace.gohighlevel.com/docs/ghl/brand-boards/set-default-brand-voice) — Set a brand voice as the default for a location. The previous default will be unset.
