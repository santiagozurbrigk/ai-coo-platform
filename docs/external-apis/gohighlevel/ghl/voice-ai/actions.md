# Actions

Documentation for Voice AI API

- [Create Agent Action](https://marketplace.gohighlevel.com/docs/ghl/voice-ai/create-action) — Create a new action for a voice AI agent. Actions define specific behaviors and capabilities for the agent during calls.
- [Update Agent Action](https://marketplace.gohighlevel.com/docs/ghl/voice-ai/update-action) — Update an existing action for a voice AI agent. Modifies the behavior and configuration of an agent action.
- [Get Agent Action](https://marketplace.gohighlevel.com/docs/ghl/voice-ai/get-action) — Retrieve details of a specific action by its ID. Returns the action configuration including actionParameters.
- [Delete Agent Action](https://marketplace.gohighlevel.com/docs/ghl/voice-ai/delete-action) — Delete an existing action from a voice AI agent. This permanently removes the action and its configuration.
