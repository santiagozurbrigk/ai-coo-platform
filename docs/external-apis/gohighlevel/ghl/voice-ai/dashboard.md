# Dashboard

Documentation for Voice AI API

- [List Call Logs](https://marketplace.gohighlevel.com/docs/ghl/voice-ai/get-call-logs) — Returns call logs for Voice AI agents scoped to a location. Supports filtering by agent, contact, call type, action types, and date range (interpreted in the provided IANA timezone). Also supports sorting and 1-based pagination.
- [Get Call Log](https://marketplace.gohighlevel.com/docs/ghl/voice-ai/get-call-log) — Returns a call log by callId.
