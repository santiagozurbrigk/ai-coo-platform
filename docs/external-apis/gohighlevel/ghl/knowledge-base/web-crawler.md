# Web Crawler

Documentation for Knowledge Base API

- [Preview Sitemap URLs](https://marketplace.gohighlevel.com/docs/ghl/knowledge-base/get-sitemap-preview) — Returns a paginated, searchable list of sitemap URLs without starting a crawl.
- [Start crawling and discover pages for training](https://marketplace.gohighlevel.com/docs/ghl/knowledge-base/discover-website) — Starts a website crawl that discovers pages for later AI training.
- [Get all trained page links by knowledge base](https://marketplace.gohighlevel.com/docs/ghl/knowledge-base/get-all-website-urls-data-by-knowledge-base) — Lists discovered and trained website pages for a knowledge base, with pagination and optional URL filter.
- [Delete trained pages](https://marketplace.gohighlevel.com/docs/ghl/knowledge-base/delete-trained-urls-for-knowledge-base) — Removes trained website pages from a knowledge base so the AI no longer references them.
- [Get crawling status for the latest operation](https://marketplace.gohighlevel.com/docs/ghl/knowledge-base/get-crawling-status-for-latest-operation) — Fetches crawl/train progress for a specific operation, or the latest operation when operationId is omitted.
- [Train discovered website pages and ingest into the knowledge base](https://marketplace.gohighlevel.com/docs/ghl/knowledge-base/train-discovered-urls) — Queues selected discovered pages so the AI ingests their content into the knowledge base.
