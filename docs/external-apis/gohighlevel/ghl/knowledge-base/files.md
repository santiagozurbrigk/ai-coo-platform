# Files

Documentation for Knowledge Base API

- [Get all files by knowledge base](https://marketplace.gohighlevel.com/docs/ghl/knowledge-base/get-files-by-knowledge-base-public) — Lists files uploaded to a knowledge base, with optional pagination and name search.
- [Uploads a file to knowledge base (max file size: 10MB)](https://marketplace.gohighlevel.com/docs/ghl/knowledge-base/upload-file) — Uploads a PDF, DOC, or DOCX file (max 10MB) into a knowledge base for training.
- [Get file by id](https://marketplace.gohighlevel.com/docs/ghl/knowledge-base/get-file-by-id) — Retrieves one uploaded file by id for the authenticated location.
- [Delete a file from knowledge base](https://marketplace.gohighlevel.com/docs/ghl/knowledge-base/delete-file) — Deletes one uploaded file from the authenticated location so the AI no longer uses it.
