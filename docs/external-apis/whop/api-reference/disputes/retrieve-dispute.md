# Retrieve dispute

> Retrieves the details of an existing dispute.

Required permissions:
 - `payment:dispute:read`
 - `plan:basic:read`
 - `access_pass:basic:read`
 - `company:basic:read`
 - `payment:basic:read`
 - `member:email:read`
 - `member:basic:read`
 - `member:phone:read`
