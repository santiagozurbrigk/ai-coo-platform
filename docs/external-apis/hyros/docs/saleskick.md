# SalesKick

This guide explains how to set up HYROS tracking inside SalesKick to track pages and booked calls.

#### A. Copy the Universal Script and connect SalesKick

1. In Hyros: profile icon (bottom-left) → Settings → Tracking → copy the Universal Script

2. Go to **Integrations** → search **SalesKick** → click it → **Configure** → sign in on the redirect page

#### B. Add the script to your SalesKick form

In **SalesKick**: open the form you want to track → click **Form** (top bar) → **Settings** (left menu) → **Embed Script** → paste the Hyros Universal Script in the **Head** section → **Publish** (top-right)

#### C. Repeat for every form

Apply the script to every **SalesKick form** you want to track. **Forms** without it won't be tracked.
