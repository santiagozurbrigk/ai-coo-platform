# Manychat Integration

Learn how to track leads and calls from ManyChat widgets and automations.

If you need assistance with your ManyChat setup, please contact support for more information.

## Important Notes

Direct messages (DMs) sent via ManyChat cannot be tracked or monitored. However, depending on your setup, there may be alternative tracking options available. If you need assistance, please contact support for more information.

Hyros allows you to track leads and calls that are made inside ManyChat. Select the appropriate workflow depending on your ManyChat flow and what you're trying to track below. If these do not apply to you, then please var the support team know and we'll help you clarify how to track with ManyChat.

## Automations That Allow Tracking Back to the Ad

- All Overlay Widgets
- All Embed widgets
- Facebook Ref URL (slightly different set up, see Flow 2)

Please keep in mind that we can NOT track back to the ad using the JSON growth tool.
