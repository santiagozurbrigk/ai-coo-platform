# WebinarGeek

This document provides instructions for tracking leads from WebinarGeek Forms.

#### A. Set Up Custom URL

Click on your webinar →

**Edit webinar**

→

**Registration**

→

**Embed**

.

Under the orange button, click on the pencil icon to set your custom URL. Enter your confirmation page and add the code

`?email={{email}}`

at the end.

#### B. Install Universal Script

Copy the script below, or In Hyros: profile icon → Settings → Tracking → copy the Universal Script.
