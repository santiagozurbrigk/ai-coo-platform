# Submit a feature

At Hyros, we genuinely value our clients’ needs and welcome all ideas through our Feature Request process. This guide will show you how to use the Feature Request Portal in the Hyros app.

#### A. Access the Feature Request Portal

In **Hyros**: left menu → **profile icon** → **Submit a Feature**.

#### B. Check if it's Already Been Requested

Before submitting, search for existing requests to avoid duplicates:

Open **All Requests** → use the **search bar** at the top → look up keywords related to your idea.

#### C. Submit your Request

If no existing request matches, click **Submit Feature** (top-right) and add:

- Title — clear and specific
- Description — the issue or feature in as much detail as possible
- Screenshot or screen recording (highly recommended) — gives the Hyros team valuable context

Click **Submit Feature**.

#### D. Track and Vote

Your request appears under **My Requests** (and in **All Requests** and **Submitted Requests**).

You can also vote for other users' requests you'd benefit from by clicking the **thumbs-up** button — the more votes a feature gets, the more likely it is to be prioritized.
