# Direct Call Tracking

Use HYROS dynamic number insertion for accurate call attribution.

Please note that this is an early beta feature that is only available for US and Canada Region.

Hyros supports both Local and Toll-Free numbers, since the subscription structure for each is different an alert will pop-up when a Toll-Free number is registered.

Choose the Direct Call Tracking setup that fits your needs

- Setup 1 - **All buttons (auto):** Tracks every Call Button automatically -> no code.
- Setup 2 - **Specific buttons:** Tracks chosen Call Buttons -> needs basic code.
- Setup 3 - **Off-site numbers:** Tracks Maps, billboards, messenger, email links etc.

## FAQ

#### How Large Does my Number Pool Need to be?

The number of tracking numbers you need depends on your website traffic and how many visitors may need a unique tracking number at the same time. Because this can vary significantly between businesses, use the **Pool Size Calculator above** to determine the recommended pool size based on your traffic.

It is important that your pool is large enough to cover your active visitors. Each visitor should be assigned a unique tracking number so Hyros can accurately connect their calls with their individual session, traffic source, and browsing activity.

If your pool is too small, multiple visitors may be shown the same tracking number. When this happens, their sessions can be combined, which can result in incorrect visit histories, attribution, and sales data.

Having a larger pool provides additional coverage during periods of higher traffic and reduces the likelihood of multiple visitors sharing the same number. However, keep in mind that you are charged for each number included in your pool.

For this reason, we recommend using the **Pool Size Calculator** to find a pool size that provides enough coverage for your traffic while avoiding unnecessary numbers. If your traffic increases significantly over time, you should review your pool size again and adjust it accordingly.

#### How Can I Access my Call Recordings?

If you would like to have direct calls recorded and stored inside your Hyros account, please ensure the "Call Recording" option is turned on.

Moving forward, this will then record direct calls tracked by Hyros and store them with each call inside the call tab under the "extra data" column.
