# Clickfunnels Based Webinar

This document provides instructions for tracking leads from a Clickfunnels based webinar.

#### A. Copy Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Install the Universal Script

In **ClickFunnels**: open your webinar funnel → **Settings** → find the **Head Tracking Code** section → paste the script → scroll down → **Save**.
