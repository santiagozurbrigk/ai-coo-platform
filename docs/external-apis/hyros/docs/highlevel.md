# HighLevel

Use this guide to track GoHighLevel with Hyros. With the integration, we will be able to track leads, sales and refunds.

1

## Integrate GHL

#### A. Connect GHL

1. In Hyros: profile icon → Settings → Integrations → search GHL [→ Connect HighLevel](https://app.hyros.com/external-services/cart-integration/highlevel)

2. Name the integration → Next → follow the prompts to authorize

2

## Tracking GoHighLevel Pages

💡 Already installed the script? Skip this step.

#### A. Copy Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Install Universal Script

In **Go High Level**: **Sites** → find your funnel → click it → **Settings** → **Head Tracking Code** → paste the script → **Save**. Repeat for every funnel — funnels without the script won't be tracked.
