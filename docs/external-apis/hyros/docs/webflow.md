# Webflow

This document explains how to install the Universal tracking script on your Webflow site.

Copy the script below, or In Hyros: profile icon → Settings → Tracking → copy the Universal Script.

Then, find the site you would like to track in your Webflow workspace and click

"Settings"

here:

Inside the site settings, go to

"Custom Code"

and paste the universal script in the head code section. Save the changes and then publish.

This concludes the setup.
