# Native Checkouts and Payment Processors

Additional checkout systems and payment processors that can be integrated with HYROS.

Do not integrate a checkout system AND a processor. It will cause the checkout system to send in a sale and then cause the processor to send in the same sale causing DUPLICATE sales. Integrate only a checkout or ONLY a processor, not both.
