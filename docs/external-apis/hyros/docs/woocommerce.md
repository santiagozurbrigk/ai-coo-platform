# WooCommerce

This guide provides instructions on how to integrate your WooCommerce store with Hyros and install the Universal Script to track sales data within Hyros.

If you need any help, contact support or your onboarding manager. We are standing by!

IF YOU WANT TO TRACK RECURRING SALES

Please be aware that WooCommerce does not currently send recurring sales into Hyros by default. We currently track recurring sales for WooCommerce users who also use the YITH Subscription plugin. If you are using a different plugin for recurring sales, please contact support and we can try to make an update for your particular case to track recurring sales.

Track Cost of Goods with WooCommerce

To accurately track the cost of goods in your WooCommerce store, you need to install the following FREE plugin: [Cost of Goods for WooCommerce](https://wordpress.org/plugins/cost-of-goods-for-woocommerce/#installation). For detailed installation instructions, please refer to the Optional Steps section below.

#### A. Install the Hyros Plugin in WordPress

In **WordPress** → **Plugins** → **Add Plugin**, [search **Hyros Tracking**](https://old-docs.hyros.com/wp-admin/plugin-install.php?s=hyros&tab=search&type=term), then **Install** and **Activate**.

Installing isn't enough. Make sure you click Activate.

#### B. Integrate WooCommerce in Hyros

1. Copy your store URL (e.g. https://yourstore.com)

2. In Hyros: profile icon → Settings → Integrations [→ WooCommerce](https://app.hyros.com/external-services/cart-integration/woocommerce)

3. Click Connect, paste your URL, click Create

4. On the redirect, click Approve
