# Product Filters

Filter by product or category to analyze your data for specific products.

---

#### Set Up Product Filtering

1. In Hyros: open the Reports tab → select your report type

2. Find the Attribute Filters section → click Specify Attributes

3. Open Filter Products

4. Search for the product you want — three ways:

- Full name — type the complete product tag
- Prefix — type the start of the product tag
- Text contains — type any portion of the product tag

5. Select the product(s) — they appear on the right

6. Select the product(s) — they appear on the right

---

#### Filter by product categories

For larger catalogs, individual product filtering gets tedious. Use **product categories** to group related products and filter by the group instead.

**Example:** if you sell products through both Shopify and a separate app, you might create:

- A category for **Shopify products**
- A category for **other app products**

Selecting one category filters the report to all products in that group automatically — no need to select them individually.
