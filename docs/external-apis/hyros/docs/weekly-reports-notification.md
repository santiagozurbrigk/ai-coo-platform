# Send Weekly Reports Notification

Receive weekly report notifications every Monday with a summary of your sales data.

## Overview

If you are sending weekly reports or you want to see a weekly report, you can use this feature!

It will be created for the accounts that send the weekly report, and the link will be sent through the notification and the email that is already sent.

Also, the reports will be sent every Monday.

Please keep in mind that if you don't receive any sales, you will not receive any report.

## Disabling Notifications

If you want to stop receiving these notifications, that is not a problem; you can disable them.
