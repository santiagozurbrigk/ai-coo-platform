# SavvyCal

This guide will show you how to track SavvyCal calls using Hyros.

1

## Install Universal Script

Please ensure you have placed the Universal code on your call booking and call thank you pages.

2

## Track Calls

#### A. Confirm Automatic Call Rule

In **Hyros**: **Tracking** → **URL Rules** → confirm the **Automatic Call** rule is listed.

Do not delete this rule.

#### B. Access SavvyCal

In **SavvyCal**: left menu → **Scheduling Links** → click the link you want to track → in the editor → **Booking Page Options**.

#### C. Configure Redirect URL

Set up:

- Booking confirmation: Redirect to a custom URL
- Redirect URL: your thank you page (on your own domain)
- Append event information to the query string: ON

Save your changes.
