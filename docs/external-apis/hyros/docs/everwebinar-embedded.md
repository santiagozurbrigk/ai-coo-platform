# Everwebinar/Webinarjam Opt In Embedded On Any Other Page (Or HTML)

This document provides instructions for tracking leads from Everwebinar/Webinarjam Opt In Embedded On Any Other Page or HTML.

#### A. Copy the Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Install the Universal Script in Everwebinar

In **EverWebinar**: **My Webinars** → edit your webinar → **Integrations** → **Third Party Tracking System**.

Paste the same script into **all three** of these fields:

- Registration Page Tracking
- Registration Form Tracking
- Post-Registration Thank You Page Tracking

#### C. Install the Universal Script on your Custom Page

In your landing page, paste the script in the page's `<head>` section — **as high as possible**, before the closing `</head>` tag.
