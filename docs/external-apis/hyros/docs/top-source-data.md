# Top Source Data

Generate a quick reference widget to see the most relevant sources from your ad platforms.

## Overview

This option will allow us generate a quick reference widget to see the most relevant sources from your ad platforms. From your Hyros dashboard please click on

Add Widget

:

Then click on

Top Table

and select

Top Sources

:

## Configure the Widget

After this we just need to configure the following:

- The traffic sources you want to display in the widget
- The attribution type
- The grouping method of the sources
- Add if needed any specific tags/products/source links from Specify Attributes
- Select the metrics you want displayed in the widget

After the options have been configured please click on

Insert

to add the widget to your dashboard.
