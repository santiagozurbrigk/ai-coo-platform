# Attribute Filters

With this guide, you'll learn how to effectively use a wide range of filters and attributes to customize your reports.

## Overview Filters

#### Set Up Source Filtering

- In Hyros: open the Reports tab → select your report type
- Find the Attribute Filters section → click Specify Attributes
- Pick the filter level you need (see below)

#### Filter Levels — Pick What Fits your Analysis

You can filter at any level of granularity, from a whole traffic source down to a single ad:

| **Filter Level** | **When to use it** |
| --- | --- |
| **Traffic Source** | Compare data across platforms (e.g. Facebook vs Google) |
| **Campaigns (Categories tab)** | Analyze data for one or more specific campaigns |
| **Ad Sets / Ad Groups** | Drill into specific audience groups within a campaign |
| **Ads** | Analyze individual ad performance |
