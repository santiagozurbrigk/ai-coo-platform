# Product Recommendation Quizzes for Shopify

Configure tracking for RevenueHunt Product Recommendation Quizzes on your Shopify store.

Please be aware that this guide specifically covers the add-on from RevenueHunt. Other similar add-ons may be tracked differently, so please reach out to the support team if you are using any other quiz add-on.

If you are using the add-on from RevenueHunt, first please make sure you are tracking your Shopify Store in the

[main Shopify Guide](https://marketplace.gohighlevel.com/docs/shopify)

above this one.
