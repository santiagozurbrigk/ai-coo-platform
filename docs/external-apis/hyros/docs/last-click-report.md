# Last Click Report

This guide walks you through how to effectively use Last Click attribution data to identify which last sources in customers journey are contributing to conversions.

---

#### Generate a Last Click report

In **Hyros**: **Reporting** → **Performance Report** → set **Attribution Model** to **Last Click** → choose your **time frame** → **Generate Report**.

---

#### How it works — Example

Imagine a customer's journey looks like this:

1. Click on a Meta ad (first source within the time frame)

2. Later, click on a Google ad (last source before the sale)

3. Make a purchase

In a **Last Click report**, the sale is credited to **Google** — because Google was the last source the customer interacted with before buying. In a **First Click report**, the same sale would be credited to **Meta**.

You can verify this by opening any sale in the report and inspecting the customer journey — the first and last sources will be visible in the timeline.
