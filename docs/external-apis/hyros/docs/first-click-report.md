# First Click Report

This guide walks you through how to effectively use First Click attribution data to identify which initial sources are contributing to conversions.

---

#### Generate a First Click report

In **Hyros**: **Reporting** → **Performance Report** → set **Attribution Model** to **First Click** → choose your **time frame** → **Generate Report**.

---

#### How it works — Example

Imagine a customer's journey looks like this:

1. Click on a Meta ad (first source within the time frame)

2. Later, click through a Google organic search result (last tracked source before the sale)

3. Make a purchase

In a **First Click report**, the sale is credited to **Meta**, because Meta was the first source the customer interacted with. In a **Last Click report**, the same sale would be credited to **Google organic**.
