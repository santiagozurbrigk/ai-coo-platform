# LTV for a Segment

LTV for a Segment is an attribution model that calculates the average long-term value (LTV) of a specific group of leads based on their initial source or product interaction. It helps you understand how much revenue a defined segment of customers generates over time.

## Overview

This report allows you to answer key questions like:

- How much should I spend to acquire leads for a specific product?
- What should my cost per sale be to stay profitable in the long term?
- Which front-end products bring in the most valuable customers over time?

---

#### Generate an LTV for a Segment report

In **Hyros**: **Reporting** → **Create Report** → set **Attribution Model** to **LTV for a Segment** → choose.

1. LTV date range (longer = more accurate)

2. Origin point (optional — specific source or product)

3. Advanced Options:

- Filter by source tag
- Exclude leads without sales
- Ignore recurring sales

---

#### Reading the report

- Product breakdown chart: the top products contributing to total LTV in your time frame
- Searchable product list: find any product and see its individual % contribution to total LTV

**Example:** If a specific product contributed `2.64%` of the total 3-month LTV, you can see how much long-term value it brings in _beyond_ the initial sale.

---

#### Using the data to scale

The most actionable use of this report is comparing a segment's LT V to your cost per sale for that segment:

1. Pick a front-end product or entry-point source

2. Generate this report filtered by that segment

3. Compare the LTV to what it costs you to acquire a sale of that product

If LTV > Cost Per Sale → that product is a profitable acquisition channel; scale it.

If LTV < Cost Per Sale → buyers of that product aren't generating enough lifetime value to justify the acquisition cost.
