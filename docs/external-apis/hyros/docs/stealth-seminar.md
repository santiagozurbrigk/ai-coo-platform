# Stealth Seminar

This document provides instructions for tracking leads from Stealth Seminar.

#### A. Copy the Universal Script

Copy the script below, or In Hyros: profile icon → Settings → Tracking → copy the Universal Script.

#### B. Access Stealth Seminar Webinar Settings

In **Stealth Seminar**: find the webinar you want to track → **Edit** → **Miscellaneous** → **Edit** on **Tracking Code Setup** → paste the script into **Header Tracking Code**.

Repeat for **every page** you want to track. Pages without the script won't be tracked.
