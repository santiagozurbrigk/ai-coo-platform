# Creating Custom Audiences

Learn how to create and sync custom audiences with Facebook and Google for targeted marketing.

## For Facebook

[**If you haven't integrated with Facebook yet, click here before following the video above.**](https://marketplace.gohighlevel.com/docs/facebook-ads)

After syncing an audience with Facebook, that audience should be synced daily automatically moving forward.

## For Google

After syncing an audience with Google, it will initially sync with any previous applicable leads in Hyros and then will be synced daily automatically moving forward.
