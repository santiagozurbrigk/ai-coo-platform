# Uscreen

This document explains how to install the Universal tracking script on your Uscreen pages.

#### A. Copy the Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Open Uscreen's Theme Code Settings

In **Uscreen**: **Customization** → on your **live theme**, click **Advanced** → select **Code Snippet** from the dropdown → paste the script into the **Head Code Snippet** field → **Save**.
