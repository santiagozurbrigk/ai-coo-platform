# Performance Reports

Attribution models to identify which sources are contributing to conversions.

## Attribution Models

Different ways to attribute sales to traffic sources.

[First Click Report](./first-click-report.md) — Identify which initial sources contribute to conversions

[Last Click Report](./last-click-report.md) — Identify final sources before conversion

[Scientific Report](./scientific-report.md) — Merges First and Last Click attribution

[Depreciation Report](./depreciation-report.md) — Time-weighted attribution model

[Linear Report](./linear-report.md) — Fractional attribution across touchpoints

[U-Shaped Report](./u-shaped-report.md) — Distributes credit across first, mid, last touchpoints
