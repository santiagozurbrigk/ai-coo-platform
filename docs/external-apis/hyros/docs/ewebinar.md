# eWebinar

This document provides instructions for tracking leads from eWebinar.

#### A. Copy Universal Script

Copy the script below, or In Hyros: profile icon → Settings → Tracking → copy the Universal Script.

#### B. Access Webinar's Script Settings

In **eWebinar**: open the webinar you want to track → **Edit** → **Registration** → **Script and Pixels** → **Add New Script** → name it `Hyros`.

- In eWebinar: open the webinar you want to track → Edit → Registration → Script and Pixels → Add New Script → name it Hyros.
- Paste the script into the Code section

#### C. Apply the Script to All Three Locations

Click **Use in Webinars** → select **all three** of these locations → **Save and Publish**:

- Landing Page
- Registration Form
- Webinar Room
