# GoHighLevel Pages

This guide will show you how to set up tracking on GHL pages.

Please contact support or your onboarding analyst directly if you have any questions about this process.

#### A. Copy the Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Install the Universal Script in Go High Level

In **Go High Level**: **Sites** → find your funnel → click it → **Settings** → **Head Tracking Code** → paste the script → **Save**.

Apply the script to every Go High Level funnel you want to track. Funnels without the script won't be tracked.
