# Adding tags to leads via Zapier

Apply specific tags to leads who provide their email address using Zapier.

  Click the link

  [HERE](https://zapier.com/app/zaps)

  to access your Zapier account.

  Create a new zap and select the system you're using.

  Configure the action by selecting Hyros (latest version) in Choose application and event. In the setup action, add the tag in the Tags field.
