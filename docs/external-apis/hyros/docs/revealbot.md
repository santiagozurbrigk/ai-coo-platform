# RevealBot

WARNING!! Be advised that if you use RevealBot’s functionalities with Hyros you will do it at your own risk as there could be some delays between integrations at this time.

## How to integrate Hyros with RevealBot

With Revealbot, you can automate ad management tasks and set up flexible rules to optimize and scale ad campaigns. RevealBot now has an integration with Hyros, and in order to integrate, please follow the steps below:

1. First, you will need to find your API key in Hyros. Please go to your Hyros account in the _Settings_ menu and copy the_API key_ from the _Profile_ tab:

2. Secondly, you will need to connect Hyros to your Revealbot account using the API Key. Please go to the Hyros tile on the_Integration Page_ under the _Attribution section_, enter your API key, and click _Connect:_

**This concludes the integration process for RevealBot. For more details on how to set up specific metrics, please refer to the integration guide on the RevealBot website**[**here**](https://help.revealbot.com/en/articles/6700815-how-hyros-integration-works)**.**

**Please feel free to reach out to our support team if you have any questions for this integration.**
