# Troubleshooting AI Pixel

Learn how to verify that HYROS is sending conversion events correctly to your ad platforms.

This applies to Facebook, Google, TikTok and Snapchat at this moment in time.

If you encounter an issue with the events or notice any discrepancies

One of the first things you will need to rule out is if HYROS is sending the data to your ad platform correctly.

You can do exactly that in 2 ways inside HYROS:

1. Checking the "Status" Column when deep diving into sales to see all sales regardless of the ad platform.

2. Going to the specific ad platform integration and checking which events have been sent to that specific ad platform.
