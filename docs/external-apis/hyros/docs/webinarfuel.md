# WebinarFuel

To track your WebinarFuel pages, just follow these steps.

#### A. Copy the Universal Script

Copy the script below, or In Hyros: profile icon → Settings → Tracking → copy the Universal Script.

#### B. Access Webinar Settings

Go to your webinar settings by selecting "webinars", clicking on your webinar that you want to track, and then selecting "settings" below:

#### C. Select Third Party Tracking

Inside your webinar settings, go to third party tracking:

#### D. Install Universal Script

Paste the script in the following fields and save:

- Webinar room
- Webinar room replay
- SAW CTA
