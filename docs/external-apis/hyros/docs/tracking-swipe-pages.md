# Tracking Swipe Pages

To track any funnel pages inside of SwipePages, first copy the universal script

#### A. Copy the Universal Script

In **Hyros**: **profile icon** (bottom-left) → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Paste it into your Swipe Pages landing page

In **Swipe Pages**: select the landing page you want to track → **Settings** → **Tracking Codes** dropdown → paste the script in the **Head** section.
