# Konnective Manual Checkouts

Konnektive offer a direct integration to Hyros within their dashboard. To set this up just follow these steps.

#### A. Get API Key

In **Hyros**: open your account settings ([API Key page](https://app.hyros.com/settings/general/api-keys)) → copy your **API Key**.

#### B. Activate Hyros Plugin

In **Konnektive**: **Admin** → **Plugins** → find the **Hyros Plugin** → click **Activate** → paste your API key when prompted → click **Connect**.
