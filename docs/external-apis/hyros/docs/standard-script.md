# Standard Script Installation

This guide will show you how to install the Universal script across your site. It's essential to add it to EVERY PAGE, including opt-in pages, sales pages, thank-you pages, checkout pages, and any other pages users might visit.

Check the lists of apps below, where the tracking setup is explained for each system in detail.

If you can't find your app on the list, don't worry, just follow the steps explained in the video above.

To track your entire funnel, simply place the **UNIVERSAL** code below in the header of every page of the funnel.
