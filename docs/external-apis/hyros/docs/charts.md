# Charts & Visualizations

Use different types of charts in your widgets to visualize data in various ways.

## Overview

If you're looking to use different types of charts in the widgets, you can use this option to visualize them in different ways.

This depends on the type of chart that suits you best.

Currently, we support

pie charts

and

line charts

.

This option is only available for widgets like the

Report Widget

and

LTV Widget

. This is because some metrics cannot be compared and would only cause confusion when reviewing them.

A correct example would be comparing qualified calls vs. non-qualified calls.
