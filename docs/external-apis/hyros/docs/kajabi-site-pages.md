# Kajabi Site Pages

This document provides instructions for tracking leads from Kajabi Site Pages.

#### A. Copy the Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Install the Universal Script

Inside Kajabi go to Settings → Site Details → Header Page Scripts and paste the script → click Save.
