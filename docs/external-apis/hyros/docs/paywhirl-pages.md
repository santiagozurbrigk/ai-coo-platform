# Paywhirl Pages

This guide will show you how to set up tracking on your Paywhirl pages.

#### A. Open Custom Tracking Scripts in PayWhirl

In **PayWhirl**: **Apps and Integrations** → scroll down to **Custom Tracking Scripts** → **Install App** → name your integration.

#### B. Install the Universal Script

1. Copy the script below, or In Hyros: profile icon → Settings → Tracking → copy the Universal Script.

2. Back in PayWhirl: paste the script into the field → make sure it's set to apply to every page → Save Settings
