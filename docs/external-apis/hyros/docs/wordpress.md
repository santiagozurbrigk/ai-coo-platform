# WordPress Pages

Install HYROS tracking on WordPress sites.

---

#### A. Copy the Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Paste it into your WordPress Theme Header

In **WordPress**: **Appearance** → **Theme File Editor** → select your active theme → **Theme Header** (`header.php`) → paste the script as high as possible in the `<head>`**section** → **Update File**.
