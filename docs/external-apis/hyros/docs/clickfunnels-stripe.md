# ClickFunnels + Stripe Integration

If you use Clickfunnels checkout pages and Stripe payment processor, the easiest way to track your sales is to follow the instructions below.

This document explains the steps required to link your Stripe account to Hyros for tracking sales events.

#### A. Install the Hyros script on Your Funnel

💡 Already installed the script? Skip to Step B

1. In ClickFunnels: open your funnel → Settings → find the Head Tracking Code section

2. Copy the script below, or In Hyros: profile icon → Settings → Tracking → copy the Universal Script.

3. Paste the script into ClickFunnels' Head Tracking Code → scroll down → Save

#### B. Connect Stripe in Hyros

Back in **Hyros**: **Settings** → **Integrations** → **Payment Processors** → find **Stripe** → **Configure** → [**Create Integration**](https://app.hyros.com/external-services/cart-integration/stripe) → follow the prompts.
