# TikTok Shops

This document explains the steps required to link your TikTok Shops account to Hyros for tracking sales events.

#### A. Connect TikTok Shop

1. In Hyros: profile icon → Settings → Integrations → search TikTok Shop → click it [→ Connect TikTok Shop](https://app.hyros.com/external-services/cart-integration/tiktok_shop)

2. Name the integration (anything you like) → Next → log in with the account you want to integrate → follow the prompts to authorize
