# Sources Tab

This document will guide you how to navigate and use the Sources Tab inside Hyros

Please note that you don’t need to create sources manually in most cases, Hyros generates them automatically based on your tracking parameters (paid traffic, organic links tracked with specific parameters, and URL rules). Manual source creation is only needed in specific scenarios that are explained in the video below.
