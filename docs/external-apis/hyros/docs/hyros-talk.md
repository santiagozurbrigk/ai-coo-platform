## FAQ

#### Can't Share Files Between Slack and Hyros Talk?

In some cases files or screenshots shared over Slack won't be visible in Hyros Talk, to correct this we need to make sure the right permission settings are enabled. From Slack, please go to **Settings & Permissions** then click on **Permissions**:

Scroll down and confirm the **Enable public file URL** creation option under **Public File Sharing** is enabled and complete the process by clicking on **Save**:

For more details about Managing Public File Sharing from Slack please go to [**Slack Help Center > Manage Public File Sharing**](https://slack.com/help/articles/4412651915539-Manage-public-file-sharing)
