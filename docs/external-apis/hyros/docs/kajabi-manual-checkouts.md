# Kajabi Manual Checkouts

This document explains the steps how to set up the tracking on your Kajabi Checkout Pages where you are manually running customer's cards.

#### A. Integrate Kajabi

1. In Hyros: profile icon → Settings → Integrations → search Kajabi [→ Connect Kajabi](https://app.hyros.com/external-services/cart-integration/kajabi)

2. Click the gear icon → Get Webhook → copy the webhook URL

#### B. Install Webhook

In **Kajabi**: **Settings** → **Checkout** → scroll to the **Webhook** section → paste the webhook into the **Purchase Webhook URL** field → save.
