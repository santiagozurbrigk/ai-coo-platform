# InstaPage Pages

This document explains the steps required to install the Universal Script on your InstaPage funnels.

#### A. Copy the Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Install it into your Instapage funnel

In **Instapage**: click the funnel you want to track → **Scripts and Privacy** (bottom of the page) → make sure **Head** is selected → paste the script into the field → **Save**.
