# Framer Pages

This document explains the steps required to track your Framer pages using Hyros

## Install the Universal Tracking Script

#### A. Copy the Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Install the Ccript in Framer's Custom Code

In **Framer**: from your dashboard, select the project you want to track → top-right **Settings** → **Custom Code** → **Add Script** → configure:

- Name: Hyros (or anything you like)
- Placement: Start of <head> section
- Pages: All Pages (recommended) — or select a specific page if you only want to track one
- Run: On Every Page Visit
- Paste your tracking script into the Code section → Add.

Top-right corner → **Publish**.
