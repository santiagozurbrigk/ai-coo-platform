# LTV for Sources

LTV for Sources is an attribution model that calculates the average long-term value (LTV) of leads generated by each traffic source over a selected time period. It helps you understand which sources bring in the most valuable customers by measuring how much revenue each source's leads generate over time.

## Overview

This report allows you to answer key questions like:

- Which traffic sources generate the highest long-term value?
- How does the average LTV of each source evolve over a specific period?
- Am I paying too much to acquire leads from a certain source?
- Which traffic sources should I scale or reduce spending on?
- How accurate and reliable is my LTV data based on available lead volume?
- How much can I afford to spend per lead on a given source and still be profitable long term?

#### Generate an LTV for Sources Report

In **Hyros**: **Reporting** → **Create Report** → set **Attribution Model** to **LTV for Sources** → choose:

- LTV date range (longer = more accurate)
- Group By: Traffic Source
- Specify Attributes (optional — filter by specific sources, ad accounts, products, etc.)
- Advanced Options: exclude recurring sales if needed
- Click Generate Report.

---

#### Reading the report

Once generated, the report shows:

- Graph view: your top 5 sources and how their LTV evolved over time — useful for spotting trends
- Data table: ranked sources with their key metrics

| Metric | What it tells you |
| --- | --- |
| **Long-Term Value (LTV)** | Average customer value over the period — the main metric |
| **Total Leads** | How many leads each source brought in |
| **Total Sales** | How many sales came from those leads |
| **Time to Acquire** | How long it took to convert each lead into a customer |

Using the data to scale

Compare each source's **LTV** to your **cost per lead** for that source:

- **LTV > Cost Per Lead** → profitable; consider scaling
- **LTV < Cost Per Lead** → losing money over time; modify or pause
