# Leadpages

This document provides instructions for tracking leads from Leadpages.

#### A. Copy the Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Install the Universal Script in Leadpages

In **Leadpages**: edit your page → **Page Settings** → **Analytics** → paste the script into the **Head Section Tracking Code** field → **Save**.

#### C. Install the Universal Script to Pop-ups and Iframe opt-ins (if any)

If your page contains a **pop-up opt-in** or any **iframe opt-in**, the page-level script won't reach it — you need to add the script separately to each one:

1. Click the pop-up or iframe → Edit Pop-Up

2. In the left menu: Settings → paste the script in the Head Section Tracking Code field → Save

Pop-ups and iframes need the script separately.

Even though they're on the same page, they render in their own context. Without the script installed directly inside them, opt-in submissions from the pop-up or iframe won't be tracked.
