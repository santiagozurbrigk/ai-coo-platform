# Keap/InfusionSoft

This document explains the steps required to link your Keap/InfusionSoft account to Hyros for tracking sales events.

1

## Track Keap Pages

#### A. Copy Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Install Universal Script

In **Infusionsoft**: **Order Forms** → select the order form → **HTML Areas** → paste the script in the **Header Area**.

Apply the script to every order form or checkout page you want to track. Pages without it won't be tracked.

2

## Integrate Keap

#### A. Connect Keap

1. In Hyros: profile icon → Settings → Integrations → search Infusionsoft [→ Connect Infusionsoft/ Keap](https://app.hyros.com/external-services/cart-integration/infusionsoft)

2. Name the integration Keap(or anything you like)

3. You'll be redirected to log in to Keap— follow the prompts to authorize
