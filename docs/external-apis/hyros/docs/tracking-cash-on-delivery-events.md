# Tracking Cash On Delivery Events

Configure how cash on delivery orders are tracked.

By default, Hyros will ignore "Cash on Delivery" events because money is not actually received.

However if you would prefer to track this sale even if it is not paid, then just turn this toggle on inside your WooCommerce integration and we'll process these events once the order has the "PROCESSING" status:
