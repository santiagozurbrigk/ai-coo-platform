# AIR Setup for Shopify

This document will guide you on how to integrate AIR into your Shopify store. This guide is intended exclusively for Shopify users (for other funnel types, refer to the AIR for All Other Funnels guide)

In order to fully complete your setup, go to the section which corresponds with the email auto responder that you're using.

### Klaviyo + Shopify

If you're using Klaviyo to send emails, your setup is already complete – there's nothing else you need to do.
