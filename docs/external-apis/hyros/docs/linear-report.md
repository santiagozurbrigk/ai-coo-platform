# Linear Report

Similar to the Depreciation Report, Linear Fractional Reporting is a multi-touch attribution model that evaluates and allocates revenue across multiple touchpoints in a user's journey. However, unlike Depreciation, it assigns equal credit to all tracked sources, giving each interaction the same weight regardless of its position in the customer journey.

---

#### Generate a Linear report

In **Hyros**: **Reporting** → **Performance Report** → set **Attribution Model** to **Linear Fractional** → choose your **time frame** → **Generate Report**.

---

#### How it works — Example

Imagine a customer's journey looks like this:

1. Click on a Bing ad (first click)

2. Click on a Google ad (middle click)

3. Click on a Facebook ad (last click)

4. Make a $200 purchase

Here's how revenue is distributed:

| Source | Attribution % | Revenue Share |
| --- | --- | --- |
| **Bing** | 33% | $66.67 |
| **Google** | 33% | $66.67 |
| **Facebook** | 33% | $66.67 |

Each source receives an equal share — `0.33` in the Sales column and ~$66.67 in revenue.
