# Stripe or Any Checkout System

Track conversions when using Stripe to manually run cards or via a checkout system.

1. Integrate with your [Stripe processor](https://app.hyros.com/external-services/cart-integration/stripe)

2. If you have plugged Stripe into a checkout system where you run the customer's card, ensure that no tracking is on this page or the system will track your reps and not the customer

3. When your sales team runs a customer card, make 100% sure to run the card with the email of the BOOKED call and phone number

We line up the conversions with the booked call email and phone number. If your team uses different emails or no phone numbers, conversions will not be tracked.
