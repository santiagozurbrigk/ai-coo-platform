# Unbounce Pages

This document explains how to install the Universal tracking script on your Unbounce pages.

If you need any help, contact support or your onboarding manager. We are standing by!

Important!

Please note that there are two types of Unbounce pages: AMP pages and non-AMP pages. At this time, Unbounce does not allow AMP pages to be tracked, only Non-AMP pages. If you are not sure what type of pages you are using, please contact your dedicated onboarding agent or inApp support.

#### A. Copy the Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Add a New Script in Unbounce

In **Unbounce**: **Settings** → **Script Manager** → **Add Your First Script** → choose **Custom Script** → name it (e.g. `Hyros`) → click **Add Script Details**.

#### C. Configure the script

Under **Script Details**, fill in:

- Placement: Head
- Included On: All
- Script content: paste the Hyros Universal Script

Under **Script Usage**: make sure your **domain is added**.

Placement and Included On must match exactly (Head + All)

Setting Placement to Body or limiting Included On to specific pages will cause incomplete tracking.
