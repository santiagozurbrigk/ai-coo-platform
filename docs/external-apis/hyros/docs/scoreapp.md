# ScoreApp

This guide will show you how to track forms/scorecards with ScoreApp.

Keep in mind that you will need **business plan** in Scoreapp to have the ability to install Scripts. You can confirm by either checking the section for tracking scripts or checking inside the billing section if you have the plan

#### A. Copy the Universal Script

In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Install the Universal script into ScoreApp scorecard

In **ScoreApp**: click the scorecard you want to track → left menu → **Settings** → **Tracking** → paste the script into the **Custom Header Script** field → **Save**.

Setup completed. Repeat for every scorecard.
