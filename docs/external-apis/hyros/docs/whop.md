# Whop

This document explains the steps required to link your Whop account to Hyros for tracking sales events.

#### A. Get Credentials from Hyros

In **Hyros**, you'll need two values:

- Pixel ID: profile icon → Settings → Tracking → copy the Pixel ID from the Universal Tracking Script section
- API Key: Settings → API Keys → click Edit → make sure the key has Full Access → copy the key

#### B. Add the Credentials in WHOP

In **WHOP**: left menu → **Dashboard** → **Settings** → scroll to the **Analytics** menu → click **Hyros** → fill in:

- Pixel ID: paste from Step 1
- API Key: paste from Step 1

Click **Save**.
