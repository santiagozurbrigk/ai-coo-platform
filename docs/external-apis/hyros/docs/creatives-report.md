# Creatives Report

The Creatives Report is a performance analysis tool that helps identify which creatives are driving the most revenue or highest ROI, so you can make data-driven decisions on which ads to scale.

#### How to Use Creatives

---

#### Generate a Creatives report

In **Hyros**: **Reporting** → **Other Reports** → **Creatives Report** → configure:

1. Attribution Model: pick the model that fits your analysis (e.g. First Click for top-of-funnel creatives, Last Click for closing creatives)

2. Date range: the period to analyze

3. Traffic source: filter to a specific platform (e.g. Facebook) via Specify Attributes

4. Filter level: Campaign, Ad Set, or Ad

5. Ad component: Image, Headline, or Copy

6. Display: Gallery or Table view

7. Advanced Options:

- Discard attribution for specific cases
- Filter by product to focus on creatives that sold a specific product

---

#### Reading the report

By default, the report sorts by **Total Revenue**. For creative optimization, **sort by ROI** instead — high revenue with high spend isn't as useful as high revenue with low spend.

For each creative component, you'll see:

- Image / Headline / Copy preview — the actual creative element
- Total Revenue — revenue attributed to that creative
- Ad Spend — what you spent on ads using that creative
- ROI — return on investment

**Example:**

| Creative | Ad Spend | Revenue | ROI |
| --- | --- | --- | --- |
| **Top Image** | $13 | $283 | ~21.8× |

In this example, the top image generated **~$283 in revenue from just $13 in spend** — an exceptional ROI. Reusing this image in other ads is likely to produce similar returns.

---

#### Using the data to scale

1. Sort by ROI instead of total revenue

2. Identify the top-performing creatives (high ROI, low spend = strongest signal)

3. Reuse the winning components in:

- New ad sets within the same campaign
- Different campaigns targeting similar audiences
- Other platforms (if the headline or image is platform-agnostic)

4. Pause or replace low-ROI creatives — they're consuming budget without returning value

5. Test new variations based on winners — iterate on what's working instead of starting from scratch

6. Make data-driven decisions when scaling campaigns, allocating budgets, and choosing which creatives to test next
