# PayPal Manual

Track conversions when using PayPal to manually run cards or via a checkout system.

1. Integrate with your PayPal processor [here](https://app.hyros.com/#/mh/external-services/paypal)

2. When your sales team runs a customer card, make 100% sure to run the card with the email of the BOOKED call and phone number

We line up the conversions with the booked call email and phone number. If your team uses different emails or no phone numbers, conversions will not be tracked.
