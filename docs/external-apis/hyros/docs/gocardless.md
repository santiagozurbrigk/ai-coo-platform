# GoCardless

This document explains the steps required to link your GoCardless account to Hyros for tracking sales events.

1

## Integrate GoCardless

[Click the **GoCardless integration link** in Hyros](https://app.hyros.com/external-services/cart-integration/gocardless) → log in to **GoCardless** when prompted → follow the on-screen instructions to authorize the connection.
