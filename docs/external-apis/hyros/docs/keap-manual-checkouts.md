# Keap Manual Checkouts

This document explains the steps required to connect Infusionsoft Checkouts to Hyros and how to track sales if you are manually running customer's credit cards.

#### A. Integrate Keap

1. In Hyros: profile icon → Settings → Integrations → search Infusionsoft → [→ Connect Keap](https://app.hyros.com/external-services/cart-integration/infusionsoft)

2. Name the integration Infusionsoft (or anything you like)

3. You'll be redirected to log in to Infusionsoft — follow the prompts to authorize
