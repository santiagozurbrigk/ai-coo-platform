# WaveApps

This document explains the steps required to link your WaveApps account to Hyros for tracking sales events.

#### Connect Wave Apps

1. In Hyros: profile icon → Settings → Integrations → search Wave Apps → click it [→ Connect Wave Apps](https://app.hyros.com/external-services/cart-integration/waveapps)

2. Name the integration, log in to Wave Apps with your credentials, and authorize the connection
