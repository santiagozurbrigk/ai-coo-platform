# Wufoo Form Integration

This guide provides a step-by-step guide on how to track Wufoo Forms.

## Written Guide

1. Add the following parameter to your thank you page url BASED on the ID on your form. Replace XX with email ID:

**?email={entry:FieldXX}**

2. Place the the Universal Tracking Script in the header of your thank you page.
