# Systeme.io Pages

This document explains the steps required to track your [System.io](http://System.io) pages inside Hyros.

#### A. Copy the Universal Script

Copy the script below, or In **Hyros**: **profile icon** → **Settings** → **Tracking** → copy the **Universal Script**.

#### B. Install it into your Systeme.io Settings

In [**Systeme.io**](http://Systeme.io): top-right **profile image** → **Settings** → **Sales Funnels** → paste the script into the field.
