# Source Configuration

Note! In this document, you will explore the source configuration option within the Performance report. This feature allows you to customize how traffic sources are displayed, giving you the flexibility to view detailed information about where your traffic is coming from, whether it’s paid or organic.

## All sources:

In this option, all the traffic sources tracked by Hyros will be displayed, regardless of whether they come from ads or organic sources. All sources will be included and visible.

### How does “Prioritize Paid Sources” work

In this option, organic traffic will be excluded from the journeys, meaning only paid ads will receive sales attribution. However, organic traffic will still be visible in the report.

### How does “Prioritize Organic Sources” work

In this option, organic traffic will be prioritized, so sales will be attributed to organic sources (if the lead contains any within its journey). Paid sources will still be visible in the report, but they will not receive attribution.

### How does “Only Organic” sources work

In this option, only organic traffic sources will be displayed, along with their attribution. Paid sources will be completely ignored and will not be visible in the report.

### How does “Only Paid” sources work

This option will display only paid sources and will not show any organic sources (whether automatic or general). Additionally, sales attributed to organic traffic will not be included.
