# SDK Overview

Drop a secure, hosted payment form into any website or app. Full theming, event hooks, and a clean React SDK.

ℹ Two ways to integrate

- **Hosted JavaScript** — One <script> tag. Works on GHL, WordPress, Squarespace, Wix, Webflow, plain HTML. — `<script src="cdn.embedded.fanbasis.io/embed/index.js">`
- **React & Next.js** — Native components, hooks, and TypeScript types. Built on the same core engine. — `npm install @fanbasis/checkout-react`

ℹ Documented versions

This documentation reflects `@fanbasis/checkout-core@0.5.0` and `@fanbasis/checkout-react@0.4.0`. New in 0.5.0: `coupon:applied` / `coupon:error` events and the `applyCoupon()` / `removeCoupon()` methods. The 0.4.0 release added native field **prefill**, per-field **hide/disable** control, top-level `metadata` and `collectPhone` options, and the `form:validation` / `field:value` events. See [Migration Guide](#sdk-migration) for details.

Use the sidebar to navigate the full SDK documentation, including configuration options, event hooks, prefill & field control, programmatic submission, platform-specific guides, and troubleshooting.
