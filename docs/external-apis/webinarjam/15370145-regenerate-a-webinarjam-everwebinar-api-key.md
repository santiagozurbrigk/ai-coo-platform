# Regenerate a WebinarJam / EverWebinar API Key

The API key functions as a secure identifier that allows third-party applications to connect with WebinarJam. If the key has been compromised, misplaced, or is no longer functioning as expected, regenerating it ensures account security and restores proper integration.

**Important:**The API key can only be **r****egenerated once every hour**. If you reset it, you must wait 60 minutes before generating a new key again.

Regenerate the API key:

  Click on the **Advanced** option next to any webinar heading.
​

  [![Advanced settings for a webinar](https://webinarjam-b76537054df6.intercom-attachments-1.com/i/o/l6vyxewd/2454313848/a2a6a6a4a28edf80071300864c77/upload_16401055675623758835.png?expires=1788058800&signature=0266891e308299b081e23501d1e0fa97df3d2ace4eacb30204463bf36f877479&req=diQiEsp%2FnolbUfMW1HO4zU0BYeIhMCB3MNoDKyvOxyodi3xtWzRGUfZt6Z6r%0AgBy8%0A)](https://webinarjam-b76537054df6.intercom-attachments-1.com/i/o/l6vyxewd/2454313848/a2a6a6a4a28edf80071300864c77/upload_16401055675623758835.png?expires=1788058800&signature=0266891e308299b081e23501d1e0fa97df3d2ace4eacb30204463bf36f877479&req=diQiEsp%2FnolbUfMW1HO4zU0BYeIhMCB3MNoDKyvOxyodi3xtWzRGUfZt6Z6r%0AgBy8%0A)

  Go to **API custom integration**.

  Click on the **R****egenerate API key icon** next to the API key.
​

  [![Regenerate WebinarJam API Key](https://webinarjam-b76537054df6.intercom-attachments-1.com/i/o/l6vyxewd/2454313855/2197e89dc569b2569190389e864d/upload_13010289242179823701.png?expires=1788058800&signature=4de015d98530bd081de3f7d2661b30262ddbe43a188fbd4a5399176b4e04b021&req=diQiEsp%2FnolaXPMW1HO4zSJBI%2BMjV8qIGKM0BKqck0fekzhzBemYlgWNuKGm%0Ady6p%0A)](https://webinarjam-b76537054df6.intercom-attachments-1.com/i/o/l6vyxewd/2454313855/2197e89dc569b2569190389e864d/upload_13010289242179823701.png?expires=1788058800&signature=4de015d98530bd081de3f7d2661b30262ddbe43a188fbd4a5399176b4e04b021&req=diQiEsp%2FnolaXPMW1HO4zSJBI%2BMjV8qIGKM0BKqck0fekzhzBemYlgWNuKGm%0Ady6p%0A)

  Click **Confirm** in the pop-up box.
​

  [![Confirm option to regenerate API key](https://webinarjam-b76537054df6.intercom-attachments-1.com/i/o/l6vyxewd/2454313860/39f345f22c5aa269ce348963c211/upload_15358269048604156114.png?expires=1788058800&signature=b60eda0f1c1ef906513c8c5b853c5019deb1105979c6676c1feb11462b361a0c&req=diQiEsp%2FnolZWfMW1HO4zS8dfPkrjB2dhxZnWdJPlsGsIt%2BZQQgLmO5SQCqL%0ALDnV%0A)](https://webinarjam-b76537054df6.intercom-attachments-1.com/i/o/l6vyxewd/2454313860/39f345f22c5aa269ce348963c211/upload_15358269048604156114.png?expires=1788058800&signature=b60eda0f1c1ef906513c8c5b853c5019deb1105979c6676c1feb11462b361a0c&req=diQiEsp%2FnolZWfMW1HO4zS8dfPkrjB2dhxZnWdJPlsGsIt%2BZQQgLmO5SQCqL%0ALDnV%0A)

  The system will show a **confirmation message** for a few seconds in the API custom integration box.

  The regenerate icon will be disabled for an hour after you generate a new API key. Hovering over the icon will show the remaining time.
​

  [![Success message after regeneration API key](https://webinarjam-b76537054df6.intercom-attachments-1.com/i/o/l6vyxewd/2454313863/93cddebca6310eacaa0fe8c21abc/upload_9688578930865693641.png?expires=1788058800&signature=7b43ee3c89282e4a509d75530e224f4cd2a1a9022afe09f0a03891995f7ceb0c&req=diQiEsp%2FnolZWvMW1HO4zV4p%2BbLSyeEeSVC4ptdPyoY37xn5%2FcEbuUlxts6X%0A8yXW%0A)](https://webinarjam-b76537054df6.intercom-attachments-1.com/i/o/l6vyxewd/2454313863/93cddebca6310eacaa0fe8c21abc/upload_9688578930865693641.png?expires=1788058800&signature=7b43ee3c89282e4a509d75530e224f4cd2a1a9022afe09f0a03891995f7ceb0c&req=diQiEsp%2FnolZWvMW1HO4zV4p%2BbLSyeEeSVC4ptdPyoY37xn5%2FcEbuUlxts6X%0A8yXW%0A)

  A **confirmation email** is sent to the account owner after the API key is refreshed.
​

  [![Confirmation email after API key reset](https://webinarjam-b76537054df6.intercom-attachments-1.com/i/o/l6vyxewd/2454313871/2957e342d8efa772302bfa643289/upload_8420226774786499363.png?expires=1788058800&signature=22043b5f5a407c9afadc0794e99676c009737afa13537ef057d614c6361dc60a&req=diQiEsp%2FnolYWPMW1HO4zevgY5ofBVWOsx2zBwHPYfaUTya6495HOEmGwG8h%0AYUkp%0A)](https://webinarjam-b76537054df6.intercom-attachments-1.com/i/o/l6vyxewd/2454313871/2957e342d8efa772302bfa643289/upload_8420226774786499363.png?expires=1788058800&signature=22043b5f5a407c9afadc0794e99676c009737afa13537ef057d614c6361dc60a&req=diQiEsp%2FnolYWPMW1HO4zevgY5ofBVWOsx2zBwHPYfaUTya6495HOEmGwG8h%0AYUkp%0A)

**Important:**Once your API key is reset, **ensure the new key is updated in all connected third-party applications** to maintain uninterrupted integration. The previous API key will no longer be valid.
