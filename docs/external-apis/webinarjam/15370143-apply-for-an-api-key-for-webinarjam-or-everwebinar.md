# Apply for an API key for WebinarJam or EverWebinar

**Approval is required** before you can use the WebinarJam / EverWebinar API. Once approved, your API access is valid for both WebinarJam and EverWebinar. Only one set of API keys is generated per account.

Go to your account **Profile > API** to apply:

  Click the **profile icon** in the top right corner of your dashboard to open the **Profile**

## Check your plan

API access is available for paid subscribers only. If you are in a trial and need to apply for the API, go to the Billing tab in your profile to upgrade to a paid plan.

# API application

**Provide information about how you will use the API:**

  Enter the URL of the app you want to use with the API. This could be the URL of custom software you developed to use our API or the URL of a third-party app that requires an API key to connect (such as Zapier).

  Describe how the app will use the API.

  Click the toggle on or off to indicate whether your app will subscribe users to your webinars.

    If yes, provide some additional information about how you get the contact information that will be sent to WebinarJam through the API.

  Add any additional notes about your app. This can include login credentials to a demo account or any other information that may be useful in our review of your request.

  Click Apply to submit your application for review.

API requests are typically processed within two business days. Once approved, your API access is valid for **both WebinarJam and EverWebinar**. Only one set of API credentials is generated per account.

Learn more about how to [connect to WebinarJam / EverWebinar API](https://support.webinarjam.com/en/articles/15370144-connect-to-webinarjam-or-everwebinar-api).
