# Use WebinarJam and EverWebinar APIs

**Applies to:**WebinarJam and EverWebinar

The API allows you to connect WebinarJam and EverWebinar with your own applications or automation tools.

Use it to manage webinars, register users, and sync data across systems.

---

# What you can do with the API

Use the API to:

  retrieve webinar data from your account

  register users for webinars

  access registrant and attendee information

  manage subscriptions and user status

  connect with external tools and workflows
